# 💊 CiaFarma

Sistema de gerenciamento de farmácia desenvolvido em **PHP**, utilizando o padrão de arquitetura **MVC** e banco de dados **MySQL**.

## 📋 Sobre o projeto

O CiaFarma foi desenvolvido com o objetivo de facilitar o gerenciamento de uma farmácia, permitindo o cadastro, consulta, edição e exclusão de informações de forma organizada.

O sistema substitui controles manuais, tornando o gerenciamento de medicamentos, fabricantes e vendas mais eficiente.

---

## 🚀 Funcionalidades

### 💊 Medicamentos
- Cadastro de medicamentos
- Listagem de medicamentos
- Edição de medicamentos
- Exclusão de medicamentos

### 🏭 Fabricantes
- Cadastro de fabricantes
- Listagem de fabricantes
- Edição de fabricantes
- Exclusão de fabricantes

### 🛒 Vendas
- Registro de vendas
- Listagem de vendas
- Atualização de vendas
- Exclusão de vendas

### 📊 Dashboard
- Quantidade total de medicamentos cadastrados
- Quantidade total de fabricantes
- Quantidade total de vendas

### 🔍 Pesquisa
- Pesquisa por palavra-chave nos Medicamentos cadastrados.
